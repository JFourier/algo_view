# Algo View

在浏览器里逐步执行 9 种算法，同步观察 JavaScript 语句、数组、链表、森林、调用栈和 DP 状态表，以及每一步的变量与结果。

## 本地运行

需要 Node.js 22.12+（本次验证使用 Node.js 24）。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 http://127.0.0.1:5173 。

```sh
npm test        # 执行引擎与播放器的行为测试
npm run build   # TypeScript 检查与静态构建
npm run test:e2e # Playwright 桌面与手机浏览器流程
npm run preview # 预览 dist 中的生产构建
```

浏览器测试优先使用 macOS 上已安装的 Google Chrome。其他环境先执行 `npx playwright install chromium`；测试配置会使用 Playwright Chromium。所有依赖版本已锁定在 `package-lock.json`。`dist/` 可以部署到静态托管服务，当前未配置线上部署。

## 使用方式

1. 在左侧展开算法分类并选择具体算法，使用默认示例或输入逗号、空格分隔的整数，点击「生成演示」。
2. 点击「下一步」，同步查看已执行语句、执行后数据和本步说明。
3. 播放、暂停、调速，或用上一步、进度条和重置反复核对。

并查集输入节点数和逐行操作（`union a b` 或 `find x`），可切换「启用路径压缩」。内置「观察路径」与「路径压缩」示例使用同一组操作，便于比较两次 `find 7` 的访问路径。快速排序提供普通、重复值和已经有序三类示例。

插入排序可观察暂存 `key` 和逐项右移；线性查找允许无序输入。链表反转输入逗号或空格分隔的节点值，跟踪 `prev/current/next` 与每次连接修改。递归斐波那契和 DP 斐波那契输入同一个整数 `n`，对照重复调用与状态复用。

当焦点不在表单或按钮上时，左右方向键单步执行，空格播放或暂停。修改输入立即停止原演示并进入待生成状态；切换算法直接加载该算法的默认示例。

导航按算法的 `category` 自动分组，目前包含排序、查找、数据结构、链表、递归与回溯、动态规划。分类可独立展开、收起，不影响当前演示；新增其他分类的算法时，菜单会自动增加对应分组。

手机上的算法导航、长链表和 DP 表分别在自己的区域内滚动，避免挤出播放控件或撑宽页面。

## 已确定的算法与回放规则

- 展示代码为 JavaScript，只读；实现为独立 TypeScript 算法模块。
- 冒泡排序使用双层 `while` 循环，不提前终止。先复制输入，再进行稳定排序；本实现额外空间为 O(n)。比较和交换是不同步骤。
- 二分查找使用闭区间 `[left, right]`，接受非递减数组；无序输入提示修正，不自动排序。重复目标返回执行时遇到的匹配下标，不保证最左位置；失败返回 −1。
- 快速排序使用固定右端基准的 Lomuto 分区，仅将严格小于基准的值放到左侧，先递归左区间再递归右区间。数组副本保留元素身份；相等值不保证稳定排序。自交换也记录语句，但不会制造元素移动。
- 插入排序先复制输入，暂存当前元素 `key`，只右移严格大于它的元素，再写回；相等值保持原顺序。数组槽位显示真实赋值后的内容，移位时可能暂时出现同一元素的副本，暂存区保留被覆盖的元素。已排序前缀仍可能移动，不提前标记为最终位置。
- 线性查找从左到右检查原始数组，无需有序；返回第一个匹配下标，失败返回 −1。
- 链表反转接受最多 24 个节点，值域与数组相同；空输入表示空链表。输入顺序决定初始 next 连接，节点身份独立于数值；逐步保存 next、反转连接和推进指针，最后更新并返回新头。节点位置固定，所有连接和 null 指针均随快照回放。
- 两种斐波那契均定义 F(0)=0、F(1)=1，接受 0—10 的整数 n。递归版按左子问题、右子问题的顺序求值，显示累计调用次数；DP 版逐项读取依赖并写入状态表，未计算项不伪装为 0。两种版本的结果约定相同。
- 调用栈保存每次调用的独立编号、参数和局部变量。进入函数时高亮调用位置；返回步骤区分刚退出的调用与已恢复的调用方，返回值赋给调用方变量后才标记赋值完成。
- 并查集允许 0—16 个节点、最多 32 条操作；节点编号为 `0` 至 `n - 1`。忽略空行，非法命令、参数或节点引用提示具体行号；0 个节点只接受空操作序列。
- 按集合大小合并；相同大小时编号较小的根成为新根。根不一定是集合内编号最小的节点。同集合合并不重复改变大小和集合数量。
- 路径压缩默认关闭，开启后对独立查询与合并内部的查询统一生效。先找到根，再沿原路径逐个赋值；未改变父节点的赋值也有明确说明。压缩不改变集合成员、根大小或集合数量。
- 父节点表与森林使用同一快照，箭头由节点指向父节点；仅根节点显示有效 size。合并中的父连接、根大小和集合计数分步更新，操作完成后完整一致。操作列表只显示当前步骤已产生的结果。
- 数组最多 24 项，元素和目标均为 −999 至 999 的整数；数组输入留空表示空数组。支持中英文逗号及空格。
- 默认最多 5000 个快照，包含尚未执行语句的初始状态和完成状态；超限显式报错。
- 每个快照独立深冻结，输入不会被修改。元素使用稳定身份，重复数值也能正确跟踪。
- 1× 每 900ms 前进一步，支持 0.5×、1×、2×、4×。回退、跳转、重置、重跑、切换算法会停止播放；调速继续播放并重新计时。所有过期回调均失效。
- 数组位置过渡最长 180ms。暂停或手动导航立即落到当前快照，减少动态效果偏好下不做过渡。
- 复杂度描述算法自身，不包含教学快照和语法高亮的额外开销。

## 代码结构

```text
src/
  algorithms/  算法定义：说明、示例、展示代码、校验、真实执行及注册
  engine/      共享记录类型、输入限制、语句映射、不可变快照
  player/      useReducer 播放状态与带失效标识的调度
  components/  数组、链表、森林、调用栈、DP 表、操作列表、输入编辑器、只读代码
  App.tsx      输入与算法选择，以及各展示区的组合
e2e/           桌面和手机浏览器验收流程
docs/          原始规格与实施记录
```

新增算法时实现 `AlgorithmDefinition` 并加入 `src/algorithms/index.ts`。输入区分数组、并查集、链表和整数，校验与执行均检查类型和规模；播放器仅消费统一的 `Trace`，不依赖算法名称、递归层数或操作种类。展示代码的动作使用稳定 `id`，多函数使用函数前缀；轨迹完成时验证语句映射。

测试覆盖排序与查找边界、分区不变量、稳定移位、逐次链表改边、调用返回和局部变量生命周期、DP 依赖、并查集连通性模型、逐次父节点修改、不可变与确定性、输入/步数上限、播放路径一致性和旧调度隔离。浏览器测试验证跨递归/操作回放、结构修改回退、修改输入/切换算法及手机操作。
