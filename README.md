# Algo View

在浏览器里逐步执行冒泡排序与二分查找，同时观察刚执行的 JavaScript 语句、数组、变量和判断结果。

## 本地运行

需要 Node.js 22.12+（本次验证使用 Node.js 24）。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 http://127.0.0.1:5173 。

```sh
npm test        # 执行引擎与播放器的行为测试
npm run build   # TypeScript 检查与静态构建
npm run test:e2e # Playwright 桌面与手机浏览器流程
npm run preview # 预览 dist 中的生产构建
```

浏览器测试优先使用 macOS 上已安装的 Google Chrome。其他环境先执行 `npx playwright install chromium`；测试配置会使用 Playwright Chromium。所有依赖版本已锁定在 `package-lock.json`。`dist/` 可以部署到静态托管服务，当前未配置线上部署。

## 使用方式

1. 选择算法，使用默认示例或输入逗号、空格分隔的整数，点击「生成演示」。
2. 点击「下一步」，同步查看已执行语句、执行后数据和本步说明。
3. 播放、暂停、调速，或用上一步、进度条和重置反复核对。

当焦点不在表单或按钮上时，左右方向键单步执行，空格播放或暂停。修改输入立即停止原演示并进入待生成状态；切换算法直接加载该算法的默认示例。

## 已确定的首版规则

- 展示代码为 JavaScript，只读；实现为独立 TypeScript 算法模块。
- 冒泡排序使用双层 `while` 循环，不提前终止。先复制输入，再进行稳定排序；本实现额外空间为 O(n)。比较和交换是不同步骤。
- 二分查找使用闭区间 `[left, right]`，接受非递减数组；无序输入提示修正，不自动排序。重复目标返回执行时遇到的匹配下标，不保证最左位置；失败返回 −1。
- 数组最多 24 项，元素和目标均为 −999 至 999 的整数；数组输入留空表示空数组。支持中英文逗号及空格。
- 默认最多 5000 个快照，包含尚未执行语句的初始状态和完成状态；超限显式报错。
- 每个快照独立深冻结，输入不会被修改。元素使用稳定身份，重复数值也能正确跟踪。
- 1× 每 900ms 前进一步，支持 0.5×、1×、2×、4×。回退、跳转、重置、重跑、切换算法会停止播放；调速继续播放并重新计时。所有过期回调均失效。
- 数组位置过渡最长 180ms。暂停或手动导航立即落到当前快照，减少动态效果偏好下不做过渡。
- 复杂度描述算法自身，不包含教学快照和语法高亮的额外开销。

## 代码结构

```text
src/
  algorithms/  算法定义：说明、示例、展示代码、校验、真实执行及注册
  engine/      共享记录类型、输入限制、语句映射、不可变快照
  player/      useReducer 播放状态与带失效标识的调度
  components/  SVG 数组、缓存 Shiki 高亮的只读代码、图标
  App.tsx      输入与算法选择，以及各展示区的组合
e2e/           桌面和手机浏览器验收流程
docs/          原始规格与实施记录
```

新增数组算法时实现 `AlgorithmDefinition` 并加入 `src/algorithms/index.ts`。播放器仅消费统一的 `Trace`，不依赖排序或查找事件。展示代码的动作使用稳定 `id`，不能依赖硬编码行号；轨迹完成时会验证语句映射。

测试覆盖排序与查找边界、判断及交换含义、变量作用域、不可变与确定性、输入/步数上限、播放路径一致性和旧调度隔离。浏览器测试验证实际界面同步、暂停/跳转/重置、修改输入/切换算法及手机操作。

需求基线见 [算法演示网页规格书](docs/algorithm-visualizer-spec.md)。快速排序、并查集和用户代码执行不属于本阶段。
